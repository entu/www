# Create Your Account

You can create an Entu database in a couple of minutes. There is nothing to install, no password to invent, and no payment to make — you just pick a name and sign in with an account you already have.

<!-- screenshot: signup page of entu.app with the database name field and the list of sign-in options -->

## 1. Go to the signup page

Open [entu.app/new](https://entu.app/new). This is where every new database starts.

## 2. Pick a name for your database

Type a name for your database. This name is part of its web address and **cannot be changed later**, so choose it with care. The rules are:

- 4–12 characters long
- lowercase letters, digits, and underscores (`_`) only
- must start with a letter

Entu checks availability live as you type, so you'll know right away whether the name is free.

Your database is a **private space** that holds your data — only you can see it until you invite someone else.

## 3. Sign in

Click the sign-in provider you want to use:

- **Google or Apple** — one click if you are already signed in on your device.
- **Email** — we send you a link; clicking it signs you in. No password needed.
- **Smart-ID, Mobile-ID, or ID card** — Estonian e-identity options.

If you are already signed in to Entu, click **Create** instead.

Entu never stores passwords, so there is no password to forget or leak. You can add more sign-in methods later — they all lead to the same account. Read more under [Authentication](/overview/authentication/).

## 4. You're in

That's it — you land directly in your new database as its owner. No payment and no separate invite step.

Every new database ships with a standard set of entity types, menus, and plugins, so you have a working structure to start from right away. You can add, change, or remove any of it at any time. To pull in more ready-made entity types, use the [Schema Templates plugin](/configuration/plugins/#schema-templates).

Billing is entirely separate and optional — you can set up a plan later from the billing page inside your account.
